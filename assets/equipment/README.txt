วิธีใส่รูปอุปกรณ์กีฬา
=======================

วางไฟล์รูปในโฟลเดอร์นี้ โดยตั้งชื่อไฟล์ตาม "id" ของอุปกรณ์ใน constants.py

รองรับนามสกุล: .png  .jpg  .jpeg  .gif  .webp

รายการ id ที่ใช้งานได้:
  football.png      — ลูกฟุตบอล
  basketball.png    — ลูกบาสเกตบอล
  volleyball.png    — ลูกวอลเล่บอล
  racket.png        — แร็กเก็ตแบดมินตัน
  shuttle.png       — ลูกขนไก่
  pump.png          — ปั๊มลม
  cone.png          — กรวยฝึกซ้อม
  knee_pad.png      — สนับเข่า

ขนาดรูปแนะนำ: 128×128 px ขึ้นไป (ระบบจะ resize ลงเป็น 64×64 ให้อัตโนมัติ)
ถ้าไม่มีรูป: แสดง emoji แทนโดยอัตโนมัติ

ต้องติดตั้ง Pillow ก่อน:
  pip install Pillow
